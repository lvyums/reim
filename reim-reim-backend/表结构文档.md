## 三、表关系说明

### 外键关系（逻辑关联）

1. **reim_employee.department_id** → **reim_department.reim_department_id**
   - 员工默认所属部门

2. **reim_form.reimburser_id** → **reim_employee.reimburser_id**
   - 报销单的报销人

3. **reim_form.department_id** → **reim_department.reim_department_id**
   - 报销单的报销部门

4. **reim_form.company_id** → **reim_company.reim_company_id**
   - 报销单的费用归属公司

5. **reim_form.business_type_id** → **base_business_type.business_type_id**
   - 报销单的业务类型

6. **reim_itinerary.form_id** → **reim_form.form_uid**
   - 行程所属的报销单

7. **reim_itinerary.traveler_id** → **reim_employee.reimburser_id**
   - 行程的出行人

8. **reim_subsidy.form_id** → **reim_form.form_uid**
   - 补助所属的报销单

9. **reim_subsidy.itinerary_id** → **reim_itinerary.itinerary_uid**
   - 补助对应的行程（一对一关系）

10. **reim_subsidy_calendar.subsidy_id** → **reim_subsidy.subsidy_uid**
    - 补助日历明细所属的补助信息

11. **reim_status_log.form_id** → **reim_form.form_uid**
    - 状态日志对应的报销单

## 四、注意事项

1. **金额单位**：所有金额字段单位为"分"，存储时需注意转换
2. **逻辑删除**：业务表采用逻辑删除机制，deleted字段在方案B中可为NULL
3. **自增主键**：所有表均使用BIGINT UNSIGNED自增主键
4. **业务主键**：原业务主键降级为唯一业务键，用于外部关联
5. **时间戳**：所有表包含create_time和update_time字段，update_time自动更新
6. **状态枚举**：各表的状态字段均有明确的枚举值定义
